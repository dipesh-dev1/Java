# Java Programming

A collection of Java programs and practice exercises written while learning Java and object-oriented programming. The code moves from core language basics to object-oriented concepts and common programming tasks, with an emphasis on clean, readable, well-structured code.

## What this repository covers

- Java basics: variables, data types, operators, input and output
- Control flow: conditions and loops
- Arrays and strings
- Methods and recursion
- Object-oriented programming: classes, objects, constructors, inheritance, polymorphism, abstraction, and encapsulation
- Interfaces and abstract classes
- Exception handling
- Collections framework: `ArrayList`, `HashMap`, `HashSet`, and more
- File handling
- Multithreading basics

## Getting started

### Prerequisites

- [JDK 8 or newer](https://www.oracle.com/java/technologies/downloads/)
- Git (optional, for cloning)

Check that Java is installed:

```bash
java -version
```

### Clone the repository

```bash
git clone https://github.com/dipesh-dev1/Java.git
cd Java
```

### Compile and run a program

```bash
javac HelloWorld.java
java HelloWorld
```

Replace `HelloWorld` with the name of the program you want to run. The class name must match the file name.
